---
name: First-use scope boundaries
description: Product boundaries confirmed while clarifying SiteSort for first-time construction users.
---

The 14-day trial starts only after account creation, email verification, login and payment-detail entry. Improve the explanation without bypassing or reordering those steps.

Construction Programmes are a document category. Do not interpret this as Microsoft Project, spreadsheet or PDF programme import into milestones unless separately requested.

Invoices are lightweight incoming and outgoing payment tracking with optional project assignment. They are not valuations, variations, subcontract orders, retentions or construction job costing.

Use construction-standard RAMS wording in the interface while keeping existing stored values and API behaviour compatible.

Daily reports already collate photos logged through site activity. Prefer clear guidance and a route to the existing photo uploader over creating a separate report-photo relationship.

**Why:** First real-user feedback showed discoverability and terminology problems, but the underlying workflows were intentional and mostly already functional.

**How to apply:** When future feedback asks for these capabilities, first distinguish clearer wording and navigation from a genuine expansion of product scope.
