---
name: Company storage allowances
description: Product decision for a future SiteSort storage entitlement and upgrade model.
---

If SiteSort introduces storage allowances, apply them per company account and map them to the existing three price tiers. Do not create separate project or individual-user quotas.

**Why:** Project documents, compliance evidence and site photos are shared company assets. A company-level allowance matches ownership and creates a natural, fair upgrade path as a contractor grows.

**How to apply:** When this feature is built, calculate usage server-side across every company-owned upload type, expose it to account owners, warn before the cap, and preserve access to existing files if uploads are temporarily blocked.
